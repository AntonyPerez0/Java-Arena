About the engine

The compiler is OpenJDK's javac 21 compiled to WebAssembly with teavm-javac and TeaVM (Apache 2.0). Programs run on Ristretto, a Java virtual machine written in Rust (MIT or Apache 2.0), with the OpenJDK 21 class library (GPLv2 with the Classpath Exception). Everything is downloaded from this site once and then kept on your device, so it also works offline. Licenses and source code.
