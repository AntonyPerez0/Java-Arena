# Fidelity suite

Java Arena computes every expected output with a real JDK 21 at build time, and grades learners' code with the in-browser engine. They must agree. This suite checks that they do.

- `programs/NN-name/`: 44 small programs in the style of the course. Each has `Main.java` (some also have other classes in files of their own), and optionally `stdin.txt`, `files/` (put in the program's working folder) and `meta.json` (`args`, `nondeterministic`, `note`). Together they cover Scanner input, `HashMap` and `HashSet` order (also with keys of the program's own classes, after the map has grown and had keys removed), double and float printing, `printf` rounding, seeded `Random`, `Math`, integer overflow, strings, streams, records and enums, comparators, interfaces, inheritance (an abstract class, a chain of subclasses with super calls, an interface several classes implement, `instanceof` and casts, `Object`'s methods through a subclass, and `List`, `Map`, `Set` and `Collection` variables), the techniques of part 10 (`StringBuilder`, regular expressions with `matches`, `replaceAll` and `split` and the messages of invalid ones, an enum with a constructor and methods, iterators that remove, `Comparable` and sorting with `Comparator.comparing`, `thenComparing` and `reversed`, streams with `reduce`, `IntStream`, `boxed`, `Collectors.joining` and `groupingBy`, and `Files.lines`), caught and uncaught exceptions (with causes and exit codes), the messages of list, array and string index errors, number parsing errors and null pointers (including the JVM's "helpful" null pointer messages), arrays and their default values, files through `java.io` and `java.nio.file`, `java.time`, stack overflow, `System.exit` (also with -1 and inside a static initializer), `Thread.sleep`, a misspelled and an inherited `main`, and a CPU-heavy program.
- `errors/NN-name/`: 40 programs that must not compile, the mistakes beginners make most. From 19 on they are the mistakes of inheritance and interfaces: a missing abstract method, an interface method without `public`, a parent without a constructor that takes no values, `super(...)` after other statements, an `@Override` that replaces nothing, `new` on an abstract class or an interface, `implements` and `extends` swapped, a subclass's method called through the parent's type, a parent-type value put in a subclass variable, a parent's private variable used in a subclass, method bodies where there must be none, and an `@Override` in a class whose header uses the wrong keyword or on a method named like a static method of its parent. From 32 on they are the mistakes of part 10: a lambda that uses a local variable that changes, a lambda that gives back the wrong type or nothing, stream methods called on an array, a list or a map, an `Optional` used as a number, `Comparable` and `Comparator` without a type in angle brackets and sorting objects that aren't `Comparable`, `new` on an enum and a `public` enum constructor, an enum constant without its enum's name, and a lambda parameter that Java types as `Object` after `Comparator.comparing(...)`, also when two of the program's classes have the method the lambda calls.

Run it:

```bash
npm run fidelity:jdk        # the reference: javac and java from JAVA_HOME or the path
npm run build && npm run fidelity:browser   # the same suite through the built site in headless Chromium
```

`fidelity:browser` compares each program's stdout (byte for byte), exit code, the first line of stderr and the learner's own stack frames, and the files the program wrote. It also runs two cross-checks that separate the halves of the engine: classes compiled by the browser's javac run on HotSpot, and classes compiled by the command-line javac run on the browser's JVM. For the error programs, every line javac prints must be identical, apart from file paths and the final `N errors` count line. The report is written to `fidelity/out/report.md`, and CI fails on any difference.

The reference JDK is Eclipse Temurin 21.0.10+7 (`scripts/get-jdk.sh`, or `JAVA_HOME` if set), the same build the engine's class library comes from. It runs with `-Duser.language=en -Duser.country=US -Duser.timezone=UTC`, UTF-8 encodings and `-XX:+UnlockDiagnosticVMOptions -XX:-UseLibmIntrinsic` (so `Math.sin` and friends match what an interpreter computes). Program 29 prints an identity hash code (`Main$Book@...`), which differs between any two runs; only that part is ignored.
