Java Arena

A free, non-commercial site for learning Java, with real compiling and running right in your browser. It follows the order and topics of the University of Helsinki's Java Programming MOOC, with its own lessons and exercises.

Being built. The lessons aren't online yet. The first piece is the Java engine: the real javac 21 compiler and a Java virtual machine, both running on your device.
