# Model solutions of the Pro Track

One folder per project of [`pro-track/`](../pro-track/), with only the files that differ from the project's starter code. This repository's CI (`npm run pro-track-check`) copies them over the starter and requires every test to pass. The site never offers them for download: solve the project yourself first. See [`pro-track/README.md`](../pro-track/README.md).
